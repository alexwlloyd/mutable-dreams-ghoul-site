# Mutable Dreams 1.1 Ghoul: editor and installer

Static site for the unofficial Mutable Dreams 1.1 + GHOULBOX grit build for the M-VAVE FM-1.

- `/` the browser instrument and live hardware editor (Web MIDI)
- `/install/` the firmware installer (Web MIDI SysEx; Chrome or Edge, FM-1 on USB)
- `/firmware/Mutable-Dreams-1.1-Ghoul.fwsc` the firmware package

Not verified on a physical FM-1. Back up device banks (.mddb) first. Recovery: reinstall official
Mutable Dreams 1.1 or Stock V15.

GPL-3.0-only as a whole. Source changes against Mutable Dreams 1.1 are in `source/`
(`mutable-dreams-ghoulbox-grit.patch`, `GHOULBOX-GRIT.md`); the base is the Mutable Dreams
project and GHOULBOX by Jason Persinger. See `GHOULBOX-GRIT.md` for credits.
